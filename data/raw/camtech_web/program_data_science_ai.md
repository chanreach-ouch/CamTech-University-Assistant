    # Data Science & AI

### Course description

This program equips students with the skills to analyze complex data, design intelligent systems, and apply AI technologies across industries. Through hands-on learning in machine learning, big data, natural language processing, computer vision, and AIoT, students gain both technical depth and practical experience.
