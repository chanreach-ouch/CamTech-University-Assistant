## Program: Software Engineering

# Software Engineering

### Course description

The Bachelor of Software Engineering at CamTech University provides students with advanced technical and professional skills to thrive in the evolving IT and software industries. You will gain a strong foundation in computing, algorithms, and system design.

#### Enrolment Information

| Course availability | Year 2 and Year 3 | 
| Session intake | March, July, October | 
| Study mode | On campus |
